# practice-repo

Practicing making repos.

## Files

- `hello.py` – a tiny Python script that prints a greeting
- `notes.md` – a place for practice notes
- `.gitignore` – tells Git which files to ignore

## Try it

```bash
python hello.py
```

## Jekyll site

This repo is also a Jekyll site published with GitHub Pages:
https://alanschafer.github.io/practice-repo/

- `_config.yml` – site settings (title, theme)
- `index.md` – home page
- `about.md` – about page
- `_posts/` – blog posts named `YYYY-MM-DD-title.md`

### Theme customization

- `assets/main.scss` – overrides Minima's colors, fonts, and widths, plus custom styles
- `_config.yml` – controls header links (`header_pages`), footer GitHub link, and date format
